# FocusFlow

تطبيق عربي لتنظيم المذاكرة والمواد والمهام، مع مخطط مذاكرة مبدئي وواجهة تحليل أداء.

## المتطلبات
- Node.js إصدار 18 أو أحدث
- npm

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `focusflow` في VS Code.
3. افتح Terminal داخل المجلد وشغّل:

```bash
npm install
npm run dev
```

4. افتح العنوان الذي يظهر من Vite، غالبًا:
   `http://localhost:5173`

واجهة الموقع تعمل مع خادم API على المنفذ 4000، وأمر `npm run dev` يشغّل الاثنين معًا.

## الموجود في النسخة الحالية
- لوحة تحكم وإحصائيات.
- إضافة وحذف المواد الدراسية.
- إضافة المهام وتحديد المادة والتاريخ والمدة والأولوية.
- تعليم المهمة كمكتملة أو غير مكتملة.
- البحث عن المهام والمواد.
- مخطط مذاكرة يوزع الوقت على المواد.
- وضع داكن وفاتح.
- حفظ البيانات محليًا في المتصفح باستخدام localStorage.
- API بسيط باستخدام Express لإنشاء خطة مبدئية.

## ملاحظات مهمة
- هذه نسخة MVP كاملة قابلة للتشغيل محليًا، لكنها ليست خدمة إنتاجية منشورة.
- بيانات المستخدم محفوظة على نفس المتصفح فقط؛ لا يوجد تسجيل دخول أو مزامنة بين الأجهزة بعد.
- مخطط المذاكرة الحالي يعتمد على توزيع الوقت بقواعد بسيطة، وليس نموذج ذكاء اصطناعي حقيقيًا.
- قبل النشر العام نحتاج إضافة Supabase للمصادقة وقاعدة البيانات، وربط مزود AI من الخادم، وإضافة اختبارات وحماية ومراجعة صلاحيات.
- لا تضع مفاتيح API السرية في ملفات `src` أو في كود المتصفح.
